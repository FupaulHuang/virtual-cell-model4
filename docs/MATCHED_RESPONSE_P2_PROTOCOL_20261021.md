# One prospective response-aware P2 objective

P1 established under-recovery in all three source contexts and both heads: v1 made no calls at the fixed exploratory thresholds. The user-authorized conditional P2 is **one response-balanced hurdle predictor**, not a grid. Root prospectively approved the procedure below before P2 fitting or evaluation. The P1 fusion-based advancement rule is unchanged; stable false-call fraction remains diagnostic, not an added gate.

Reuse the exact frozen P1 raw banks, outer-context folds, training/evaluation pairs, source prior, minimum cells, native units, measured-axis inverse, CD4 exclusion and H1 exclusion. Thresholds remain absolute arithmetic log2(CPM+1) response 0.25 and natural-log bulk response 0.10. These are magnitude proxies, never DE significance. Source contexts were already examined during development.

For each outer fold, sort the union of training target IDs by SHA-256 of `20261023:target`. The first round(20% of targets), at least one, form a recalibration subset; the rest fit coefficients. Use the same target partition across the two remaining source contexts. No outer held-out response enters any coefficient fitting, recalibration, feature common component, or threshold. Within each subset preserve P1 target/gene weights and normalize each source-context task equally. Class priors and recalibration prevalence use those weights, not raw row counts.

The recalibration target labels are excluded from direct coefficient fitting, but full-source common features still include all source targets, as P1 requires. Thus this has **transductive preprocessing within the training sources**. It is not independent unseen-target reliability validation. Assess reliability on the outer held-out context; make no deployment-probability or DE-calibration claim.

## Fixed model and loss

- Responsivity: ridge logistic regression for `abs(observed effect) >= threshold`. Inputs are the ten frozen confidence features plus `log1p(abs(pooled specific))` and `log1p(abs(pooled shared))`. These are unsigned response/coverage/control/uncertainty features. Fit loss gives each response class one-half of total weight, using the original weighted fitting prevalence.
- Conditional sign: logistic regression for positive versus negative observed effect among responsive fitting rows only. Inputs are an intercept and the eighteen frozen signed response features. Keep ordinary target/context weights; decision is positive at probability >=0.5.
- Conditional magnitude: ridge regression for `log(abs(effect)/threshold)` among responsive fitting rows, using the same unsigned features and ordinary weights. Reconstruct magnitude as `threshold * exp(clip(log-excess, 0, log(3/threshold)))`. The support floor follows the responsive event's definition, rather than a quota or fallback that invents calls.
- All standardized non-intercept coefficients use ridge 0.03. Intercepts are unpenalized. Standardizers use ordinary fitting weights, never outer-context data. Fixed numerical solver limits are implementation safeguards, not tuning choices. No hyperparameter, response threshold, amplitude or source-weight search is allowed.

Fit a two-parameter monotone Platt map on the recalibration subset using ordinary target/context weights: nonnegative slope, unpenalized intercept, ridge 0.03 on the standardized slope. This corrects the class-balanced training prior and fits magnitude-proxy probabilities within the training sources. Record slope/intercept, original weighted fitting and recalibration prevalences, target counts, weight masses, Brier scores and ten fixed-width reliability bins. A nonpositive unconstrained slope yields the convex boundary solution: a constant recalibration-prevalence predictor. It yields no calls under the rule below. Missing response classes or sign classes are explicit failures with no substitute model or artificial calls.

## Fixed decision policy and evaluation

Call a response only when calibrated proxy probability is **strictly greater than recalibration prevalence + 1e-8**. This is a declared class-balanced error-cost boundary, not “more likely responsive than stable,” not an ordinary 0.5-probability policy, and not a neutral calibration repair. It was accepted prospectively as part of this changed objective/decision rule. A constant probability equal to prevalence makes no calls. Unsupported source coordinates never call. Noncalls have predicted effect zero; calls use the conditional sign and magnitude, capped at 3. No target call quota, confidence fallback, probability-threshold search or post hoc rescue is allowed.

Evaluate exactly the frozen P1 pairs, with unclipped observed responses, the same magnitude-call definitions and signed precision/recovery/error metrics. Report outer-context proxy Brier scores and reliability without using them to tune the model. Reuse the same paired target-cluster bootstrap and undefined-denominator handling. Run the same exact inverse on the complete measured destination axis for separate profile diagnostics, never on sampled genes.

Before P2 outcomes, also register one descriptive control-expression split: destination matched arithmetic control CPM >5 versus <=5, using identical masks for P2 and matched fusion and retaining original target/gene weights conditioned on each stratum. Report signed precision/recovery, calls and errors with the unchanged proxy thresholds. This is not an extra advancement gate or a new fitting choice. Low-expression magnitude changes may reflect sampling noise, and gains restricted there do not establish useful biological recovery or official-DE performance.

Advancement is exactly the P1 gate against matched fusion: both heads need higher equal-context signed recovery, nonworse equal-context signed precision and class-unweighted MSE, with no context-level signed precision/recovery regression. Use the original 1e-8 tolerance and require defined precision in all contexts. No gate is added or relaxed. Passing a proxy benchmark alone does not promote a model or authorize a submission. If this single objective fails, stop another H1 scoring cycle and identify the missing evidence rather than adding objectives or adjusting thresholds.
